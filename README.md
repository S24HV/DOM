# 🚀 DOM Manipulation Practice Project

Welcome to the **DOM** repository! This is one of my **early training projects**, specifically created to dive deep into working with the **Document Object Model (DOM)** and understanding how JavaScript interacts with HTML and CSS.

The project demonstrates dynamic content updates, rendering, and element styling entirely driven by user interaction in real time.

## 💻 Tech Stack & Core Tools
This project focuses heavily on frontend logic using:
* **HTML5** — for setting up the initial document skeleton.
* **CSS3** — for layout visual styles and dynamic class configurations.
* **JavaScript (Vanilla JS)** — for handling event listeners and updating the document structure programmatically.

## 🎯 What I Practiced & Learned
Developing this project helped me master fundamental JavaScript core features:
* **DOM Traversal & Selection:** Using methods like `querySelector`, `querySelectorAll`, and target node navigation.
* **Dynamic Content Updates:** Modifying elements on the fly via `textContent`, `innerHTML`, and altering node values.
* **Event Handling:** Attaching `.addEventListener()` to capture user actions like clicks, inputs, or form submissions.
* **State & CSS Classes:** Toggling UI styles dynamically by modifying the `classList` (adding/removing active states).
